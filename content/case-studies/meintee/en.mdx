<Chapter n="01" label="Context" />

<Lead>
meinTee sells tea sets and gifts for quiet tea moments. At its heart is a configurator for putting together a set and having it engraved.
</Lead>

When I took over the theme, the store was already live and selling every day. Like any store that has grown over time, it had a list of small issues: product images sliding under the header while scrolling, a review form in the wrong tone of voice, a cart that opened before the product was in it.

None of them was big. Together, though, details like these decide whether a store feels reliable. Because content was edited in the theme editor at the same time, every change had to be safe and traceable. So I did not start with the first fix. I started with a routine.

<Chapter n="02" label="Approach" />

## A five-step routine for every change

Every change, however small, went through the same five steps. It sounds like extra work, but it saves work: no fix overwrites someone else's changes, and every custom edit can be found again after a theme update.

<Steps>
  <Step n="01" title="Pull the live theme">Download the code straight from the store, so it matches what customers actually see.</Step>
  <Step n="02" title="Compare">Diff every file against the original theme and note what changed and why.</Step>
  <Step n="03" title="Test in the browser">Prototype each fix in DevTools on the real store first.</Step>
  <Step n="04" title="Mark it">Tag every custom change in the code so it survives theme updates.</Step>
  <Step n="05" title="Ship one file">Upload one file at a time, after checking nobody else changed it.</Step>
</Steps>

## A logo that assembles itself

Next to the fixes I built something new for the header, shown in action at the top of this page. I split the meinTee mark into three SVG layers: star, leaves and rings. On the first visit they come together between “mein” and “tee”, while the wordmark is there from the start.

Everything moves with CSS keyframes only, no library. Visitors who turned on “reduce motion” on their device see a still logo.

<Figure
  src="/images/meintee/logo-timeline.jpg"
  alt="Animation timeline: star 4.0 s, leaves 2.1 s, rings 2.6 s"
  caption="Three layers, three movements. The default values in the store."
/>

So the team can adjust it without code, the animation is configurable in the theme editor: on or off, once per session, three colours, plus size, duration and delay for each layer.
